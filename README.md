---

## Skills & Tech Used

- **Framework:** Next.js
- **UI:** React, React DOM
- **AI / LLM SDKs:** OpenAI SDK (`openai`), Google GenAI (`@google/genai`), Groq SDK (`groq-sdk`), AI SDK (`ai`)
- **Realtime Chat:** Socket.IO Client (`socket.io-client`)
- **Auth (Google):** `@react-oauth/google`
- **Backend-as-a-Service:** Firebase
- **Markdown Rendering:** `react-markdown`, `remark-gfm`
- **Animations:** Framer Motion
- **Notifications:** React Toastify
- **Icons/UI:** Lucide React
- **Styling Utils:** `clsx`, `class-variance-authority`, `tailwind-merge`
- **Code Quality / Tooling:** ESLint, `eslint-config-next`
- **CSS Tooling:** Tailwind CSS (v4), `@tailwindcss/postcss`, `tw-animate-css`

## 🚀 Run Locally

```bash
git clone https://github.com/muhamadzainalam-dev/AiChatBotApp_Fe.git
cd AiChatBotApp_Fe
npm install
npm run dev
```

Open:
```text
http://localhost:3000
```
